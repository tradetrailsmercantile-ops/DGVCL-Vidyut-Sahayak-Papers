# DGVCL Vidyut Sahayak (Electrical Assistant) Paper Archive

This repository is a research archive for **Dakshin Gujarat Vij Company Limited (DGVCL) Vidyut Sahayak (Electrical Assistant)** written-exam papers and related answer keys.

## Scope

Primary scope:
- Vidyut Sahayak (Electrical Assistant)
- Ex-Apprentice to Vidyut Sahayak (Electrical Assistant), when it is a DGVCL written exam
- Actual question papers, paper sets, OMR/response sheets where available, and official/provisional/final answer keys

Out of scope for the primary index:
- DGVCL Vidyut Sahayak (Junior Engineer / JE)
- DGVCL Vidyut Sahayak (Junior Assistant / JA)
- Other DISCOMs such as PGVCL, MGVCL, UGVCL, GETCO, GSECL, unless a source is being used only as a cross-reference

## Verification rule

A paper is marked **Verified** only when the evidence identifies DGVCL, the post, and the exam date or recruitment event. A secondary website can be evidence of availability, but its claim is recorded as secondary evidence rather than treated as an official DGVCL publication unless the underlying official document is found.

A missing paper is recorded as **Not yet found**, not as proof that no paper exists.

## Important copyright note

This archive will not assume that every third-party PDF can legally be redistributed. Where redistribution rights are unclear, the repository records the source and verification metadata rather than copying the PDF. For the 04-10-2026 paper, the archive currently records the source provenance, SHA-256 hash, structural analysis and provisional answer-key transcription; it does not falsely claim that a binary PDF has been re-hosted.

## Research objective

Find the maximum number of **genuine DGVCL Electrical Assistant papers**, distinguish them from JE/JA and other DISCOM papers, detect multiple paper types/sets, and preserve a transparent source trail.
